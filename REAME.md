# ChatAI 🤖

A simple AI chatbot that responds to user input using JavaScript.  
This project is designed as a prototype for AI-based chat applications and can be extended for more advanced features.

---

## 📝 Features
- Simple chat interface  
- Responds to user input with pre-defined AI logic  
- Can be expanded to use real AI APIs (like OpenAI)
